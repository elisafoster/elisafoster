ELISA ADMIN 操作マニュアル

ELISA Official ポートフォリオサイトのコンテンツ管理、スケジュール予約投稿、外観テーマ変更、画像アセット管理など、管理画面の全機能と操作方法を体系的に解説した公式ドキュメントです。

1

はじめに・システム概要

システムの特徴と構成

当サイトは、Cloudflare Pages / Workers、Cloudflare D1（高信頼エッジ分散データベース）、GitHub API、および Firebase Authentication を連携させた高速かつ安全なモダンWebアプリケーションです。

  • 超高速な公開サイト: 静的HTML/CSSとエッジAPIにより、世界中どこからでもミリ秒単位で高速表示されます。
  • データベース連動: お知らせやスケジュール、ショップ情報などは管理画面から即座に追加・編集できます。
  • GitHubアセット連携: 画像ファイルはGitHubリポジトリ（assets/ 配下）へ直接安全にアップロードされ、CDNを通じて高速配信されます。
  • PWA完全対応: PC・スマホのホーム画面にアプリとしてインストールでき、ネイティブアプリ感覚で快適に操作できます。
💡
推奨動作環境:
・PC: Google Chrome / Microsoft Edge / Safari / Firefox（最新版）
・スマートフォン: iOS 15以降（Safari） / Android 10以降（Google Chrome）
2

ログイン・認証と権限管理

ログイン手順

STEP 1
管理画面（admin.html）へアクセス
ブラウザで /admin.html を開きます。未認証の場合はログインカードが表示されます。
STEP 2
Googleアカウントでログイン
「Googleアカウントでログイン」ボタンをクリックし、事前に管理者として許可されているGoogleアカウントを選択します。
STEP 3
認証・権限の照合
データベース上のホワイトリスト（許可リスト）と照合され、権限に応じた管理メニューが表示されます。

ロール（権限レベル）の違い

ログインユーザーの権限（ロール）に応じて、サイドバーに表示される管理メニューや実行できる操作が自動的に制御されます。

ロール名 表示バッジ 操作可能な機能・権限範囲
Owner
（最高管理者）		 OWNER 全機能の完全権限
全コンテンツの閲覧・作成・編集・削除、GitHub PAT設定、D1データベース保守エクスポート（SQL / JSON）、アカウント管理（Ownerを含む全ロールの追加・変更・削除）。
Admin
（共同運営者）		 ADMIN コンテンツ・外観の全編集権限
プロフィール、衣装、全セクションコンテンツ、テーマ設定、セクション装飾、アセット管理、ガイドライン編集、アカウント管理（Editor / Writerの追加・編集）。
※GitHub PAT設定は非表示。OwnerおよびAdminアカウントの編集・削除は不可。
Editor
（編集者）		 EDITOR 主要コンテンツの管理権限
イベントバナー、お知らせ、スケジュール、ギャラリー、動画リスト、再生リスト、ショップ商品、リンクリストの作成・編集・削除・並び替え。
※プロフィール・衣装・外観設定・アセット・アカウント管理は非表示。
Writer
（投稿者）		 WRITER 日常的な告知・更新権限
イベントバナー、お知らせ（予約投稿含む）、スケジュールの閲覧・作成・編集のみ。
※日常のライブ告知やスケジュール更新に特化した安全な権限です。
⚠️
「アクセス権限がありません」と表示される場合:
ホワイトリスト（アカウント管理）に登録されていないGoogleアカウントでログインした場合は画面が自動的に遮断されます。OwnerまたはAdmin権限を持つ管理者に連絡し、アカウント登録を依頼してください。
3

画面構成と共通操作ルール

管理画面の基本レイアウト

  • トップバー (上部): ハンバーガーメニューボタン（スマホ時）、現在開いているタブ名、ログイン中のアカウント名・ロールバッジ、ログアウトボタンが常時配置されています。
  • サイドバー (左側 / スマホはドロワー): 各管理タブへのナビゲーションリンク、D1データベース保守ボタン、Cloudflare/GitHubの稼働ステータス、アプリインストールボタンが収められています。
  • メイン作業エリア (中央): 各機能のテーブル一覧、編集フォーム、リアルタイムプレビューなどが展開されます。

共通操作ルール（重要）

🚨
「更新反映」ボタンの仕組み（ドラフト反映型）:
テーマ設定やプロフィール、一部の並び替え設定などは、画面上で入力・編集した時点ではまだ本番データベースには書き込まれません。画面右上のオレンジ色「更新反映」ボタンを押すことで、初めてD1データベースに一括コミットされます。作業後は忘れずに「更新反映」を押してください。
🖼️
画像の選択・指定方法（3つのモード）:
管理画面内のほぼ全ての画像指定フォームでは、以下の3つの方法に対応しています：
1. ライブラリ参照: サーバー上の既存画像ファイル（assets/...）をプルダウンから選択。
2. 直URL指定 (Googleドライブ対応): Googleドライブの「リンクを知っている全員」の共有URLを貼り付けると、自動的に高速直リンクURLに変換されます。
3. 📤 新規アップロード: PCやスマホのストレージから直接画像を選択してGitHubへアップロード（※規格比率に応じたトリミング調整機能付き）。

👤 プロフィール設定

公式サイトのプロフィールセクションに表示される情報やSNSリンク・紹介動画を設定します。
管理画面上では「基本プロフィール」「ステータス」「活動プラットフォーム」「紹介動画」の4つのアコーディオンに分かれており、クリックして開閉しながら個別に編集できます。

👤 基本プロフィール

タレントの基本名称やキャッチフレーズ、自己紹介文を設定します。

項目名 必須/任意 仕様・入力説明
名前 (name) 必須 公式サイト上でメイン表示される活動名・フルネーム（例: ELISA）
ふりがな 任意 名前の読み仮名・ひらがな表記（例: えりさ）
ローマ字 任意 英字・ローマ字表記（例: ELISA）
ニックネーム 任意 愛称・略称（例: エリー）
キャッチフレーズ 任意 セクション上部に大きく表示される一言コピー。
75文字以内（リアルタイム文字数カウンター＆超過警告表示付き）
自己紹介文 任意 プロフィールカード内に表示される詳細テキスト。
180文字以内・最大5行（リアルタイム文字数・行数カウンター＆超過警告表示付き）。入力した改行はサイト側にも忠実に反映されます。

誕生日・活動開始日・ファンネームなどのスペック情報を管理します。

項目名 必須/任意 仕様・入力説明
誕生日 任意 月日ドラム式ピッカー対応（例: 07月15日）。
入力欄をクリックするとポップオーバーが開き、月・日のドラムロールを回して直感的に選択できます。
年齢 任意 数値入力（例: 18）。非公開の場合は空欄のままで構いません。
身長 (cm) 任意 数値入力（小数第1位対応、例: 158.5）
活動開始日 任意 年月日ドラム式ピッカー対応（例: 2024年04月01日）。
年・月・日のドラムロールから記念日・デビュー日を簡単に設定できます。
ファンネーム 任意 リスナーやファンの呼称（例: エリ友）

𝕏 (旧Twitter) URL 任意 公式XアカウントのURL（例: https://x.com/...）。サイト上で𝕏専用アイコンリンクとして表示されます。
追加プラットフォームURL
（枠1〜3）		 任意 TikTok、Twitch、Instagram、FANBOX、bilibiliなどのリンクを最大3件まで追加可能。

・URL: 対象ページのURL（https://...）を入力

🎬 紹介動画

自己紹介PVや歌ってみた、代表配信などの動画を最大3枠まで掲載できます。

項目名 必須/任意 仕様・入力説明
動画枠 1 〜 3
（YouTube動画URL）		 任意 掲載したいYouTube動画のURLを入力します。
通常URL（https://www.youtube.com/watch?v=...）、短縮URL（https://youtu.be/...）、Shorts（https://www.youtube.com/shorts/...）のいずれの形式でも入力可能です。
リアルタイムプレビュー 自動 URLを入力すると自動的にYouTube動画IDが抽出され、入力欄の下に実際の動画埋め込みプレーヤー（iframe）が即座に表示されます。入力ミスがないかその場でプレビュー確認できます。
💡
プロフィールの更新反映:
入力が完了したら、カード右上にある「プロフィール情報を更新」ボタンをクリックして保存してください。正常に保存されるとトースト通知が表示され、公開サイト側に即座に反映されます。

(visualBackground)		 任意 立ち絵の背面に敷く専用背景画像。

🎪 イベントバナー

新曲リリース、グッズ発売、周年イベントなどの告知バナーをサイト上に掲載・管理します。
掲載開始日時と終了日時を指定することで、期間外のバナーは自動的に非表示となる自動期間連動システムを採用しています。

📝 新規追加・編集項目一覧

項目名 必須/任意 仕様・入力説明
id 必須 管理用番号（自動採番・読み取り専用）
リンク
(link)		 任意 バナーをクリックしたときのジャンプ先URL（例: https://example.com/event）。
外部サイトや配信ページ、ショップページなどを指定します。
開始日時
(start_at)		 必須 バナーの掲載を開始する日時（カレンダー＆時計ピッカー対応）。
この時刻より前は公開サイト上に表示されません。
終了日時
(end_at)		 必須 バナーの掲載を終了する日時（カレンダー＆時計ピッカー対応）。
この時刻を過ぎると公開サイト側から自動的に非表示になります。
画像選択
(banner)		 必須 イベント告知バナー画像（推奨比率 16:9）。
・ライブラリ参照: assets/event 配下の既存画像から選択
・直URL指定: Googleドライブ共有リンク（自動変換対応）や画像直リンクを入力
・アップロード: PCやスマホから画像を直接アップロード＆トリミング
📱
スマホ画面での入力配慮:

⚠️

追加や編集が完了したら、バナー一覧画面上部のオレンジ色「更新反映」ボタンを押して保存を完了してください。

D1 データベース保守（バックアップ）

サイドバー下部にある保守機能から、データベースの定期バックアップをダウンロードできます。

  • SQLダンプ: 全テーブルのスキーマ定義とINSERT文を含む完全なSQLファイルを出力します。システム移行や障害復旧に使用します。

GitHub PAT (Personal Access Token) の設定

画像のアップロードや削除は、GitHub REST APIを通じてリポジトリへ直接コミットされます。この通信を許可するためにPersonal Access Token（Fine-grainedトークンまたはClassicトークン）を設定します（Ownerのみ設定可能）。

1
GitHubでTokenを発行
GitHubの Settings > Developer Settings > Personal access tokens にて、対象リポジトリへの Contents: Read and write 権限を持つトークンを発行します。
2
管理画面「GitHub PAT 設定」に入力
サイドバーの「GitHub PAT 設定」タブを開き、トークンを貼り付けて「保存・接続テスト」を実行します。

❓ よくある質問 & トラブルシューティング

Q. 編集した内容が公式サイトに反映されません

A. 以下の2点をご確認ください：
1. 「更新反映」ボタンの押し忘れ: テーマ設定やプロフィール等は、画面右上の「更新反映」ボタンを押すことで保存が完了します。
2. ブラウザキャッシュ: スマートフォンやPCのブラウザが古いキャッシュを保持している場合があります。ページを「強制再読み込み（スーパーリロード: Ctrl+F5 や Shift+更新）」するか、PWAアプリの場合はアプリを一度完全にタスクキルして再起動してください。

Q. 画像のアップロード時にエラーが発生します

A. 以下の原因が考えられます：
・GitHub PATの期限切れ: トークンの有効期限が切れている可能性があります。「GitHub PAT 設定」から有効な新しいトークンを再登録してください。
・ファイル容量超過: 1ファイルあたり最大2MB（装飾画像は1MB）の上限があります。トリミング調整機能で圧縮するか、リサイズツール等で縮小してアップロードしてください。

Q. Googleドライブの画像が表示されません

A. Googleドライブ上の画像ファイルの共有設定が「リンクを知っている全員が閲覧可」になっていることをご確認ください。「制限付き」のままだと外部サイトから画像を取得できません。
